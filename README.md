# EPS Command Board

An engine assembly line failure tracker for managing issues across different bus lines.

## 🚀 Live Demo

**View the app here:** https://ArjunMenonCummins.github.io/eps-command-board/

## Features

- **Kanban Board**: Organize issues by bus line (19L, 30L, 95L, 15L)
- **Issue Tracking**: Track ESN, station, and detailed descriptions
- **Meeting Log**: Record meetings and follow-ups for each issue
- **Issue Resolution**: Mark issues as resolved and track resolution metrics
- **Local Storage**: All data persists in your browser

## Usage

1. Click **+ Issue** on any line to create a new issue
2. Fill in the title, ESN, station, and description
3. Click **Open** to view details
4. Add meetings to track progress
5. Click **Issue Resolved** when complete
6. Monitor counters at the top for current and resolved issues

## Data

All data is stored locally in your browser's localStorage. No server is required.
